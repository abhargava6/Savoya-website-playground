Transportation Grouping — Quote-to-Reservation Pipeline

Dual intake (Manifest + Unstructured) → AI Conversion → Grouping → Quote → Group Discount → Tier → Vendor Negotiation → Reservation

Step 1 — Intake
Two Intake Paths
Client provides trip details — either as a structured manifest or as unstructured text/email/screenshot/PDF
Path A — Structured
Client Manifest
CSV, Excel, PDF — received from aviation dept. Arrivals, departures, transfers in separate tabs.
Path B — Unstructured
Freeform Request
Email text, screenshot, phone notes, partial info. "I need 3 SUVs in Dallas Jan 2." Team pastes into internal tool.
Step 2 — AI Processing
AI Agent
AI Conversion + Clarification
Path A: AI reads file in any format, maps columns to our schema.
Path B: AI extracts trip specs from text, asks clarifying questions for gaps, uses placeholder data for names. Conversational interface (like a chat).
Both paths merge here ↓
Step 3 — Review & Correct
Review Converted Data
System shows what AI converted. User edits any errors. Three tabs: Arrivals, Departures, Transfers. Path B shows original text alongside extracted data.
Step 4 — Grouping
Grouping Logic
Select strategy: "Recommended" (Savoya preset) or other categories (TBD). System groups travelers across all 3 legs.

Step 5 — Views + Adjust
Views + Manual Adjustment + Live Quote
Three views (Passenger, Manifest, Trip) × 3 legs. Users drag travelers between vehicles to regroup manually. Quote auto-updates in real time.
Step 6 — Discount
Apply Group Discount
Team reviews quote summary and applies a single percentage-based discount across the entire group. Total quote recalculates.

Auto-Flag Trip Count Tier

Step 9
Quote to Client
L1/L2: instant quote with discounts applied. L3/L4: final quote after vendor negotiations complete and adjustments are made.
Step 10
Conditional
Change History
Appears on re-upload or edit. Shows delta in travelers, groups, cost. Accept/reject workflow.
Step 11
List of Reservations
Final confirmed reservations — all 3 legs with vehicle assignments, pickup times, passenger lists, discounts applied.

Scope

Key deliverables for the transportation grouping / quote-to-reservation pipeline.

1
Dual Intake System
Path A: file upload (any format). Path B: internal conversational AI tool for unstructured requests (email, text, screenshots). Later: expose Path B to clients.
2
AI Conversion Agent
AI-powered ingestion — maps arbitrary formats/columns to our schema. Conversational clarification for gaps. Hardest part of the project.
3
Data Review & Correction Screen
Show AI output with inline editing. Flag low-confidence rows. 3 leg tabs. Path B shows original text alongside extraction.
4
Grouping Engine
Recommended (Savoya preset) + TBD categories + Custom. Configurable criteria per leg type.
5
Views, Manual Adjustment & Live Quote
3 views × 3 legs. Drag-to-regroup. Quote auto-updates. Group-level % discount applied during quote summary review.
6
Tier Classification & Vendor Notification
Auto-flag L1–L4 by trip count (configurable). L3/L4: send negotiation brief to vendor team with market gaps and trip details.
7
Data Schema & Microservices
Schema for manifests, trips (3 legs), groups, vehicles, quotes, discounts, tiers, change history. Backend services.
8
Change History
Track re-uploads/edits across all legs. Show delta, cost change. Accept/reject workflow.

Open Questions & Decision Points

AI model for conversion: What powers the AI agent? How do we handle confidence scores — flag low-confidence mappings for user review?
Unstructured intake — minimum fields: What's the absolute minimum info needed to generate a quote? (Date, city, pax count, vehicle type?)
Path B → Path A transition: When a quote-only request (Path B) converts into a real booking, how do real names/details get attached later?
Multi-city events: The Super Bowl example spans multiple cities over weeks. How do we handle multi-market events in the UI and grouping?
Tier thresholds: Are the L1–L4 ranges (1–15, 16–35, 36–75, 75+) confirmed? How does the team update them?
Vendor team needs: Exact details for the negotiation brief — confirming today. Missing vehicles, missing vendors, pricing gaps, out-of-market options.
Discount structure: Group-level % confirmed — one discount applied to the entire group during quote summary review. Can the discount be adjusted after vendor negotiation for L3/L4?
L2 "potential negotiation": What triggers an L2 to actually go through negotiation vs. getting an instant quote?
Quote delivery: How does the final quote get to the client? Email? PDF? Portal link? All of the above?
Transfer leg in manifests: If client doesn't include a transfers tab, do we prompt for it? Or is it optional?
Grouping for Path B: When there are no traveler names (quote-only), does grouping still apply? Or is it just vehicle sizing based on pax counts?
Vendor negotiation timeline: How long do L3/L4 negotiations typically take? Does the system track status?
